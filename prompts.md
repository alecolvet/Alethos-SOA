# Registro de uso de IA

A FIAP recomenda registrar os prompts utilizados como apoio e compreender/validar todo o código entregue. Atualize este arquivo com os prompts efetivamente utilizados pela equipe durante a implementação e revisão.

- Apoio inicial: planejamento de uma API REST para o projeto Antigolpe para Idosos, limitada aos critérios da disciplina SOA e Web Services.
- Revisão obrigatória pela equipe: conferir regras de domínio, testar os endpoints, validar as migrations e adaptar os contratos para integração com as aplicações dos demais integrantes.
